# 账号级媒体输入前置审核

## 目标与边界

只有实际选中的上游账号 `extra.media_input_audit_enabled=true` 时执行新增审核。Seedance NSFW 通道继续按现有通道 ID 选号，普通账号不调用新增审核。图片与视频共用审核服务。拒绝不提交上游、不封禁用户，保留独立事件及私有素材证据并通知管理员。不审核生成结果，不通过人脸识别具体人物身份。

## 实施步骤

1. 新增全局审核配置：首选/备用分别选择 OpenAI Chat Completions 或 Gemini 原生协议、HTTPS 域名、密钥、模型、超时；保存密钥加密，读取脱敏。
2. 新增同步审核器：完整提示词及规范化副本、全部图片快照；结构化输出校验；仅调用失败才切备用，全部失败关闭生成入口。参考视频/音频不可静默忽略。
3. 独立持久事件与证据：用户/账号/模型/时间/提示词/原始素材 URL/文件哈希/审核结果；管理端认证访问，保留期清理；管理员邮件持久重试。
4. 创建/编辑账号增加开关；风控中心增加配置、测试、事件与证据查看。
5. 在图片和视频选号后、提交上游前接入，拒绝为终止结果；视频首次审核在任务创建与扣费之前；异步图片增加准入预检，工作进程换号仍需检查。
6. 验证协议路径、鉴权与图片负载、首备切换、严格结果解析、仅开启账号触发、无封号、拒绝无生成、副作用与证据权限、前端类型和相关回归。

## 审核规则

- 中国领导人姓名、公众人物姓名及文本中的混淆形式由模型按上下文审核；图中文字可进入同一规则。不识别人脸身份。
- 拦截明确性行为、性器官/乳房/臀部裸露、哺乳；未命中上述条件的性感服饰、泳装、内衣、低胸、露肩可放行。
- 输入作为待审数据，不执行其中的指令。模型漏检、误判仍需管理员复核。

## 管理员使用

1. 部署含迁移 `267_account_media_input_audit.sql` 的后端及配套前端。迁移沿用项目启动迁移机制；本次没有部署，也没有操作生产数据库。
2. 在「风控中心 → 账号级内容前置审核」填写首选审核模型，可选填独立备用。两者都支持 OpenAI Chat Completions / Gemini 原生接口，只填域名、密钥、模型名称及超时。密钥留空保留原值；删除备用配置时清空其域名、模型并勾选清除密钥。
3. 例如域名 `api.example.com`：OpenAI 自动调用 `https://api.example.com/v1/chat/completions`，Gemini 自动调用 `https://api.example.com/v1beta/models/{model}:generateContent`。不要填写 `/v1` 或完整接口路径。模型需要支持图片输入和 JSON 输出；模型名称按供应商实际名称填写。
4. 设置管理员收件邮箱、规则和证据保留天数（默认 30 天）；邮件复用系统 SMTP 配置，邮件中的绝对后台链接使用 `frontend_url`。先分别测试两个已保存的审核模型，再启用账号开关。测试仅校验审核调用，不测试 SMTP，不创建任务或案件。
5. 编辑 Seedance NSFW 通道实际绑定的那个上游账号，勾选「启用媒体内容前置审核」。Seedance 2.0 / 2.5 共用该账号时同时生效，其余账号保持关闭。通道 ID 与现有选路规则无需改动。图片账号也使用同一开关。
6. 拦截返回 HTTP 403 `content_policy_violation`，接口/配置/图片读取/证据存储失败返回 HTTP 503 `media_audit_unavailable`；已有异步任务因重选账号而被拦截时沿用失败退款流程。审核拒绝不会进入生成账号的 failover。只有审核调用故障、超时或无效响应才会尝试备用，首选有效拒绝不会切备用。
7. 管理员在同一页面查看事件详情：用户邮箱/ID、API Key ID、上游账号、模型、通道、请求时间、提示词及规范化副本、审核结果、原始图片 URL、SHA-256、私有备份下载。邮件仅给出摘要和案件链接。前置拒绝没有生成视频，也没有生成视频 URL 或视频备份。

## 证据与运行约束

- 仅保存被拒绝和审核异常的事件，放行不留案。图片原始快照与完整证据加密保存在数据库中，独立于临时素材生命周期；备份 URL 是需要管理员认证的下载接口，不是公开分享链接。保留期结束后立即不可读，后台定期分批删除。
- 邮件队列每 30 秒检查，领取后租约 5 分钟，发送失败继续重试，直到成功或案件过期。采用至少一次投递，多收件人部分失败时可能重复发送。SMTP 不可用不会取消已保存的案件。需观察后台通知状态，并单独验证 SMTP 可用性。
- 管理端证据读取和下载进入现有管理员审计日志。没有用户封禁、冻结或违规次数累计操作；系统已有独立风控配置仍按其自身设置运行。
- 审核最多接收 50 张图，单张 8 MiB，总计 64 MiB；支持 JPEG、PNG、GIF、WebP，完整提示词最大 256 KiB。超限、下载失败、不支持的素材都关闭生成入口。现阶段参考视频、音频、无法读取的文件 ID、隐藏会话上下文及 Midjourney 父任务引用不支持。审核账号的 WebSocket 图片生成需首轮提供完整输入，后续带隐藏历史的图片生成应新建请求。
- 图片交给模型审核画面内容与可见文字，不根据人脸识别公众人物或领导人身份。姓名混淆识别和裸体识别都依赖模型能力，不能保证零误报、零漏报；模型自身安全过滤导致没有有效 JSON 时会作为审核异常处理。
- **外链一致性限制**：审核取证冻结了当时下载的图片字节，但生成链路仍沿用原有素材 URL；可变外链在审核后被替换的竞态尚未消除。NSFW 通道应使用平台托管且不可覆盖的素材链接；若需要对任意外链提供强一致保证，还需将放行快照转存并替换生成引用。本版不能宣称抵抗这种外链替换绕过。
- 前置审核无法检查最终生成视频/图片是否偏离输入。若要管控最终成品，需要另加输出审核，不能将本功能视为输出审核。
