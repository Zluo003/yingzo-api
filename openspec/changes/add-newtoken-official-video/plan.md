# NewToken 官方协议

- 新增独立 `newtoken_official` 视频适配器，使用官方 content tasks 协议，保留原 newtoken。
- 内置文档四个官方模型 ID，添加 Seedance 2.0 Mini；目录从账号映射自动发现，无需数据库种子迁移。
- 按文档最终渲染的说明支持各模型分辨率；账号可进一步限制模型、分辨率、时长、参考素材数量和生成模式。
- 支持公网参考素材及 asset 引用、2.5 草稿和参考视频任务类型、文档可选参数；高级引用仅路由到官方协议账号。
- 复用任务轮询、结果备份及账号审核流程。上游 usage 随结果保存；下游仍按已配置的秒/次价格结算。
- Mini 文档未单列时长和素材上限，暂沿用 2.0 系列 4–15 秒及 9 图/3 视频/3 音频；账号可收窄。
- 使用模拟 HTTP 验证创建/轮询和协议，验证账号配置、目录与前后端检查，不调用付费上游。

## 使用方式

账号管理 → 视频账号，选择需要的模型（含 Mini 时会自动选中唯一支持它的「NewToken 官方协议」），填写上游域名和 API Key。默认路径为 `/api/v3/contents/generations/tasks`，模型映射输入框显示官方默认 ID，留空即可使用；自定义映射、分辨率、时长、素材数量、生成模式、审核开关和 NSFW 通道均沿用账号配置。

默认模型映射：

| 下游模型 | 上游模型 ID |
| --- | --- |
| seedance-2.0 | doubao-seedance-2-0-260128 |
| seedance-2.0-fast | doubao-seedance-2-0-fast-260128 |
| seedance-2.0-mini | doubao-seedance-2-0-mini-260615 |
| seedance-2.5 | doubao-seedance-2-5-260628 |

## 协议和现有计费边界

- 上游域名不需要包含 API 路径；路径可独立覆盖。创建和轮询均使用 Bearer Key；结果 CDN 下载不携带上游 Key。
- 分辨率按页面最终渲染的说明：2.0 为 480p/720p/1080p/4K，Fast/Mini 为 480p/720p，2.5 为 480p/720p/1080p。NewAPI 密钥分组可能进一步限制分辨率，应在账号中勾选实际可用档位。
- 省略时长默认 4 秒。2.5 的 edit 保留 `ratio=adaptive,duration=-1`；extend 要求指定正整数输出总时长。未指定的可选参数不发送，显式 false/0 保留。
- 网关继续按配置的秒/次单价结算，没有实现上游按 Token 的二次结算。`duration=-1` 沿用已有 2.5 自动时长的 5 秒估算，不按成功响应时长重新结算；参考视频的附加计费时长只采信平台探测结果，asset 引用无法探测时按现有规则不增加该部分时长。需要准确核算这两类用量的账号可使用按次定价。
- 启用账号审核时，现有审核器无法读取的草稿、视频/音频和 asset 引用继续拒绝；公网图片按既有审核流程处理。普通账号可正常使用这些协议能力。
- 没有执行真实付费生成；创建、处理中、成功（含 usage）及失败响应均用模拟 HTTP 验证。
