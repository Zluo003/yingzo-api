# Yingzo Web Design System

## Direction
Soft modernism with Japanese restraint and editorial warmth. The public site is a creative brand surface; authenticated pages are a quiet workspace.

## Tokens
- `--ink`: #30241e — primary type and actions
- `--muted`: #84776e — supporting text
- `--paper`: #faf7f2 — panels and forms
- `--line`: #d9cfc4 — borders and dividers
- `--accent`: #415687 — focus state only
- Background: #f2ece4 / `bone`

## Typography
- Display: Playfair Display, weight 500, italic for emphasis
- UI/body: DM Sans, weights 400–600
- Kicker: 11px uppercase with 0.22em tracking

## Layout
- Desktop shell: 260px navigation rail + fluid content
- Public hero: 1fr / 1.2fr split, generous negative space
- Radius: 10–18px for controls and cards
- Actions: espresso pill buttons; outlines for secondary actions

## Content rules
- Lead with creative outcomes: stories, images, video, ecommerce content.
- Avoid positioning Yingzo as an API, dashboard, relay, or infrastructure product.
- Keep API Key management as an authenticated utility page, with no group selectors or group labels.
